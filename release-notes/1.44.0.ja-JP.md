- Little Launcher が 9 つの言語に対応しました: 英語 (米国とカナダ)、スペイン語、フランス語 (フランスとカナダ)、ドイツ語、簡体字中国語、ポルトガル語 (ブラジル)、日本語。デバイスの言語に従うほか、[設定] の [言語] で選ぶこともできます。
- 設定がすっきりと統一された見た目になりました。
- 新しい [設定をリセット] ボタンで、ランチャー、同期、ブラウザー拡張機能はそのままに、ほかの設定を既定値に戻せます。
- Web サイトのアイコンは、そのサイト自体からのみ取得するようになりました。サイトにアイコンがない場合も、Google のアイコン サービスには問い合わせません。
- 新しい一方向の OneDrive 共有では表示専用リンクを使うため、共有相手がランチャーを変更することはできません。以前に作成したリンクはそのままです。
- トレイ メニューの表記が [設定] になり、[ログ フォルダーを開く] が追加されました。
- スクリーン リーダーがすべてのボタンとフィールドを名前で読み上げるようになりました。
- 修正: 新規インストール時に、同期先がないまま SFTP 同期がオンになることはなくなりました。
- 修正: Windows エクスプローラーの再起動後もトレイ アイコンが元に戻り、更新後も残るようになりました。
- 修正: [終了] と設定のインポート後の再起動で、アプリが確実に閉じるようになりました。

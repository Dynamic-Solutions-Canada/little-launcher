- Activez ou désactivez un lanceur sur cet appareil directement depuis la liste des lanceurs dans les Paramètres, avec le nouvel interrupteur de chaque carte. Il ne se trouve plus dans les paramètres de chaque lanceur.
- Désactiver un lanceur demande désormais une confirmation sous Windows comme sous Linux, car cela ferme ses pages et arrête les médias ou les téléchargements qu’elles contiennent.
- Les lanceurs désactivés sur cet appareil apparaissent estompés dans la liste : vous voyez leur état d’un coup d’œil et pouvez toujours les modifier.

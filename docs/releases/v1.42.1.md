## Little Launcher 1.42.1

This update brings the Microsoft Store version up to date with everything added since 1.41.1, and includes security-related build updates.

- Launcher icons now stay intact when syncing to another device, including custom images and symbol icons.
- Icon selection now uses a single chooser.
- Sync destinations start collapsed, so the Sync page is easier to scan.
- Launchers created on another operating system stay in your list without trying to launch apps that can't run on this one.
- Little Launcher now starts at login by default for new installations. Existing installations keep their current choice, and you can change it in Settings.
- Little Launcher is now built with the latest patched .NET runtime.

Linux users: this release also improves AppImage packaging.

## Little Launcher for Linux

Little Launcher now runs on Linux with native desktop controls, tray launchers and an isolated Chromium web engine. Launch apps and websites, organize shortcuts into groups and columns, and keep web launchers available in their own windows.

- Download the Linux x64 AppImage for Debian 12 / Ubuntu 24.04 LTS or newer. KDE Plasma is the primary desktop; GNOME needs tray support and uses regular windows where anchored flyouts are unavailable.
- Sync web launchers and selected icons between Windows and Linux through OneDrive personal accounts. Windows and Linux shortcut launchers stay separate and appear disabled on the other operating system.
- Choose icons from websites, local images, symbols, emoji and selfh.st. Selected images travel with your launcher settings.
- Turn individual launchers off on a device without deleting them or their synced configuration.
- Use tabs, bookmark folders, icon-only bookmarks and browser extensions shared with their sign-in profile.
- Check for AppImage updates, download and install them from About, and control login startup in Settings. Startup is enabled by default for new installations on both platforms.

Earlier development AppImages may need a manual download for this first release because their updater used the repository address from before its transfer.

## Windows improvements

- Launcher icons survive syncing to another device, including custom images and rendered symbol previews.
- Icon selection uses one chooser, and cloud sync destinations start collapsed.
- Launchers created for another operating system remain listed without trying to launch incompatible applications.

## Downloads and compatibility

This release includes Windows x64 and ARM64 portable ZIPs and the Linux x64 AppImage with its checksum. Microsoft Store submission is held for this version.

Linux currently supports OneDrive personal-account sync; other sync destinations and shared-launcher transports are not enabled. Some Google sign-ins and passkey flows remain incompatible with the embedded browser, and notification behavior varies by site. Desktop placement and tray activation depend on your desktop integration. See the documentation for platform differences and remaining compatibility limitations.

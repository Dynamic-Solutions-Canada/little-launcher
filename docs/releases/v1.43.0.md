## Little Launcher 1.43.0

- Turn a launcher on or off for this device straight from the launcher list in Settings, using the new switch on each launcher card. It no longer sits inside each launcher's settings.
- Turning a launcher off now asks for confirmation on Windows as well as Linux, since it closes the launcher's pages and stops any media or downloads in them.
- Launchers that are off on this device are dimmed in the list, so you can see their status at a glance and still edit them.

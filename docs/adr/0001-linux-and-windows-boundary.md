# Develop Linux alongside the existing Windows application

Little Launcher currently has a Windows-specific implementation. Develop Linux alongside it while preserving the Windows application's broader UI and architecture and targeting compatible settings and sync where practical. Narrow Windows changes are allowed to preserve and hide OS-specific shortcut entries and to protect active calls, microphone/camera capture, and transfers from automatic unload or unconfirmed app quit, superseding the initial preference for no Windows changes. This avoids making Linux desktop integration experiments depend on a Windows rewrite, at the cost of maintaining platform implementations and explicitly testing their data compatibility. KDE is the primary Linux desktop target, with GNOME also in scope; success on one desktop does not establish acceptance on the other. The Linux toolkit decision is recorded in [ADR 0003](0003-native-linux-controls-and-isolated-web-engine.md).

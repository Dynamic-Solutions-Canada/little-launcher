# Native desktop controls with a separate Electron web engine

Use distro-integrated PySide6/Qt Widgets for Linux Settings, shortcut flyouts, and editing, while retaining a current Electron process for web launchers. The isolated KDE qualification rendered the actual Breeze style, Noto Sans font, and desktop palette, but its QtWebEngine reported Chromium 122; the separately qualified Electron 45 engine reports Chromium 156. This costs a second toolkit/process boundary, but avoids choosing between native desktop controls and a current browser engine. Control uses inherited pipes, trusted local browser chrome receives the native palette/font, and remote content receives neither Node nor the control bridge. KDE positioning uses host-supplied StatusNotifierItem activation coordinates and an optional app-scoped KWin helper; unavailable integration uses the explicitly labelled regular-window mode. Physical GNOME, fractional-scale, multi-monitor, and complete browser-workload acceptance remain separate gates.

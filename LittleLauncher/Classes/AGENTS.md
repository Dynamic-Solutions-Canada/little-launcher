# LittleLauncher/Classes

P/Invoke and native interop conventions apply here — `NativeMethods.cs` is the single home for all `[LibraryImport]`/`[DllImport]` declarations.

Read and follow [pinvoke.md](../../.codex/docs/pinvoke.md) before changing the code described above.

`IconGallery.cs`, `IconCatalogView.cs`, `SelectionReveal.cs`, `AutomaticPageIconChoice.cs` and `GlyphIconRenderer.cs` also live in this folder. When editing these, follow the icon system conventions: [.codex/docs/icons.md](../../.codex/docs/icons.md).
